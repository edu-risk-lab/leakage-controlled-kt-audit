\section{DDR augmentation operator definitions}
\label{sec:supp-operators}
All operators act on the retained acyclic $\Epre$ at perturbation strength
$p\in\{0.05,0.10,0.20,0.30\}$:
\begin{itemize}
  \item \textbf{Attribute masking} masks a random subset of edge attributes
  without changing $\Epre$ ($\DDR{=}0$ by construction).
  \item \textbf{Edge dropping} removes each edge independently with probability
  $p$ (expected $\DDR{\approx}p$).
  \item \textbf{Subgraph sampling} performs a random walk until
  $\lceil(1-p)|\mathcal{C}|\rceil$ nodes are visited and returns the induced
  subgraph (boundary edges drop; internal connectivity preserved).
  \item \textbf{Node dropping} removes $\lceil p|\mathcal{C}|\rceil$ nodes and
  all incident edges.
  \item \textbf{\texttt{prereq\_preserve}} draws the same per-edge budget as
  edge dropping but removes only transitively redundant edges, protecting the
  transitive-reduction backbone.
\end{itemize}

\section{Ground-truth disagreement examples (Junyi)}
\label{sec:supp-disagreement}
The cross-validation procedure exports qualitative disagreement cases to
\path{results/tables/disagreement_examples.csv}. Inferred-only edges are
predominantly bidirectional co-occurring arithmetic pairs (e.g.\
\texttt{number\_line} $\leftrightarrow$ \texttt{addition\_1}). Expert-only
edges are systematic level-progression annotations (e.g.\
\texttt{equivalent\_fractions\_2} $\rightarrow$ \texttt{equivalent\_fractions}).
The \texttt{wrong\_direction} category contains many reversed level-progression
pairs such as \texttt{addition\_1} $\rightarrow$ \texttt{addition\_2}.
